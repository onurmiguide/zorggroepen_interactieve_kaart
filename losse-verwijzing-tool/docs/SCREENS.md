# Benodigde schermen

## 1. Landing / uitleg
Doel:
- uitleggen wat de tool doet
- inputformaten tonen
- gebruiker naar upload leiden

## 2. Upload scherm
Elementen:
- upload knop
- drag and drop zone
- melding welk type bestand is toegestaan

## 3. Verwerking scherm
Elementen:
- status: parser / OCR / AI extraction
- bronbestand naam
- progress of stapindicator

## 4. Review scherm
Belangrijkste scherm van v1.

Elementen:
- brontekst of document-preview
- velden per categorie
- markering van onzekere velden
- handmatige editmogelijkheden
- knop voor akkoord

## 5. Resultaat scherm
Elementen:
- definitieve JSON
- kopieerknop
- export
- terug naar nieuw document

## Aanbevolen review-layout
- links document of OCR-tekst
- rechts de gestructureerde velden
- onderaan validatiemeldingen
